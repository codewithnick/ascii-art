## Special characters

SevenStar also renders `@ # $ & % ! ? * + = < >`:

```
  %%%     %  %       %     %%   %     %%        %
 %   %    %  %      %%%    %%  %     %  %       %
% %%% %  %%%%%%%   % %        %      % %        %
% % % %   %  %      %%%      %        %         %
% %%% %  %%%%%%%     % %    %        % % %      %
 %   %    %  %      %%%    %  %%    %  % %
  %%%     %  %       %     %  %%     %% %       %
```

```
 %%%%       %                           %     %
%    %   % % % %     %                 %       %
    %     %% %%      %     %%%%%%%    %         %
   %       %%%    %%%%%%%            %           %
   %      %% %%      %     %%%%%%%    %         %
         % % % %     %                 %       %
   %        %                           %     %
```
